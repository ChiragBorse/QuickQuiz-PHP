# 📖 About

**QuickQuiz** is a complete **Online Quiz Management System** developed using **PHP, MySQL, Bootstrap, HTML, CSS, and JavaScript**.

The system enables educational institutions, colleges, schools, and organizations to conduct online examinations efficiently through a secure and user-friendly interface.

It provides separate **Admin** and **Student** dashboards where administrators can manage quizzes while students can participate, view results, and track their performance.

